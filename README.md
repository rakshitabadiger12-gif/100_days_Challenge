# Ritual — 100 Day Challenge Tracker

A single-file web app (`index.html`). No build step, no dependencies.

## Put it online with GitHub Pages
1. Create a new GitHub repository and upload `index.html` and `README.md` to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- Each user's progress is stored in their own browser (localStorage). Use **Customize → Export backup** to save or move it.
- Edit the default goals in the `def()` function inside `index.html`.
